# 公开网页连接 1.2.0

独立浏览器适配包，无需登录，配置 `{}`。导入并批准后创建连接，选择“阅读公开网页”，输入 HTTPS 公网 URL。

`read(url, max_chars=12000)` 返回最终 URL、标题、渲染后的正文、最多 500 个链接、正文截断标识。页面脚本可运行，使用独立临时浏览器上下文，无其他连接的 Cookie 或持久存储，结束即关闭。不会绕过登录、验证码或平台访问限制。

HTTPS CONNECT 出口对每个目标校验公网 DNS，阻止回环、私网及非 443 端口；HTTP 页面暂不支持。读取范围是当前渲染页面，不保证分页、完整评论或所有异步内容。结构化讨论优先用专门的站点包。

`find(url, keyword, limit=20, context_chars=100)` 在完整已加载可见正文中按字面值、不区分大小写查找；返回最多 100 条匹配、Unicode 字符起止偏移（end 不含）、前后各 context_chars 个字符的上下文（默认 100，范围 0–2000，0 只返回匹配词）、是否还有更多匹配。没有匹配返回空数组。matching_links 仅包含已提取链接中标题匹配关键词的链接，不代表每条正文匹配均有链接。不自动展开、滚动或翻页。
